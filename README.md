# swot-discharge-prior-transfer

Code for the manuscript

> Kaya, Y. *Do SWOT Discharge Algorithms Improve on Their Mean-Flow Prior? A Test at 463 Gauged Reaches.* Submitted to *Journal of Hydrology*.

The repository downloads all public inputs, builds the gauge–reach pairs and three-reach chains, runs the
prior-transfer analysis and the controlled Bayesian Manning inversion (twin experiment and gauged chains), and
writes every number, table and figure used in the paper. Nothing is copied by hand into the paper: the
manuscript tables are generated by `15_tables.py` from the CSV/JSON files in `output/`.

NASA Earthdata credentials are read from `~/.netrc` (`machine urs.earthdata.nasa.gov login ... password ...`).
Large inputs and intermediate files are written to `~/swot_p38_work` (override with the environment variable
`P38_DATA`). Expected layout of that folder:

```
data/          inventories, chains, gauge locations, climatology, chain_data/, transfer/
gauges/        usgs/, wsc/, hubeau/, bom/, ana/ (daily discharge CSV), arcticgro/ (xlsx)
                + data/stations_arcticgro.csv (river, station, lat, lon, file)

```

## Environment

Tested with Python 3.14. `pip install -r requirements.txt`. Versions used for the paper are pinned.
Run all scripts from the repository root (for the scripts in `exploratory/`, use `PYTHONPATH=.`).

## Running

```
./run_all.sh            # from the first analysis step (07); download steps are listed below
./run_all.sh 08         # resume from a step
```

Download and preparation (run once, in this order): `01_sos_inventory.py`, `04_gauge_download.py`,
`05_chains.py`, `04b_gauge_eu_oc.py`, `04d_gauge_all_candidates.py`, `05c_gauge_location_all.py`,
`06_hydrocron_download.py`, `12a_transfer_data.py`.

Analysis (`run_all.sh`): `07` merge → `05b` gauge location check → `04c` 2013–2022 climatology → `07b` SWOT
consensus at chains → `12b` prior-transfer statistics → `12c` algorithm coverage → `08` gauged-chain inversion
(+ `08a`, `08s` sensitivity) → `03` twin experiment → `08d`, `08e` MCMC diagnostics → `11` summaries →
`13`, `14` figures → `15` tables.

Random seeds are fixed in every script. The full analysis takes about 1.5 h on 10 cores.

## Where each result comes from

| Paper | Script | Output |
|---|---|---|
| Section 4.1, Table 1, Figures 2–3, Table S3 | `12b_transfer_analysis.py` | `output/transfer_summary.csv`, `transfer_pairs.csv`, `transfer_numbers.json` |
| Table S1 | `12c_algorithm_coverage.py` | `output/algorithm_coverage.csv` |
| Section 4.2, Figure 4 | `03_twin_experiment_mc.py` → `11_summary.py` | `output/summary_twin*.csv` |
| Section 4.3, Table 2, Figures 5–7 | `08_chain_inversion.py` → `11_summary.py` | `output/summary_chains.csv`, `summary_sensitivity.csv`, `summary_numbers.json` |
| Table S2 | `08d_mcmc_diagnostics.py`, `08e_mcmc_long.py` | `output/mcmc_diagnostics.csv`, `mcmc_long.csv` |
| Figure 1 | `13_figures_transfer.py` | `figures/Fig1_map.*` |
| All tables | `15_tables.py` | `output/tables.json` |

Core model code is in `p38/`: `model.py` (wide-channel Manning flow law, priors, AHG and mass-conservation
likelihoods), `infer.py` (emcee sampling, feasible initialisation, KGE, coverage, contraction), `synth.py`
(synthetic reaches for the twin experiment), `paths.py` (folder locations). `DESIGN.md` records every design
decision (D1–D26) with its reason, in the order in which it was taken; code comments refer to these numbers.
Function and variable names follow the notation of the paper (A0, n, dA, Qbar, C0/C2/C3). In the result files,
`prior` is `width` (width-based mean flow, SWOT only) or `clim` (pre-SWOT gauge climatology), and `constraint` is
`C0`, `C2` or `C3`.

`exploratory/` contains two early diagnostic scripts that are not used for the results in the paper.
